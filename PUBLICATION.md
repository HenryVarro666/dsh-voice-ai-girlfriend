## Included

Source code, tests, example configuration, dependency descriptions, original license/attribution, frozen synthetic metadata, approved aggregate results and diagrams. README files explain the product question, methods, results, decisions and next work. Historical reports retain original evidence boundaries.

## Excluded

Credentials and actual local configuration; model weights/caches/vendor checkouts; virtual environments; raw or generated audio/video, binary portraits/contact sheets; private full transcripts/review state, large runtime logs, SQLite databases and career correspondence. The coordination repository also excludes private job-targeting notes.

No media is hidden in Git LFS or base64 HTML. Local-only file references are rendered as labeled text rather than broken download links. Where a PNG diagram has a corresponding SVG, documentation uses the SVG. Cross-repository links point to the separately published repositories. Personal operational paths/host addresses in documentation are generalized; experimental numbers are unchanged.

## Reproduction and limits

CPU tests and numerical summaries have their own scope. Fresh inference requires original data, model access/licenses and the documented environment. The public backup is not a complete archive of private media or trained checkpoints. GPU services were not changed or revalidated by publication.

# 数字读法规范化：独立冻结对照

2026-10-20运行前冻结。只使用既有独立0.6B模型、原音色和默认重复惩罚1.05，temperature0.9、chunk4不变。对照原始阿拉伯数字与明确中文读法；编号逐位保留前导零/重复位，年份逐位、月日时分正常整数读。仅处理显式结构化测试字段，不自动改写任意用户文本，不改显示文本，不部署。

[8条冻结场景](cases.json)：4条纯编号、4条编号+日期时间；seed4409/5519/6619，各策略24条，共48条。包含6/8/9位、前导零、重复零、五分/三十分、午夜、闰日。所有数值虚构。任务交错顺序seed20261023，另2次预热不计分，不替换失败输出。

记录实际参数、EOS/撞上限、PCM/原始时长与首声。计时为handler调用到首有声/生成耗尽，不含ASR或完整对话；EOS追踪有开销。无裁剪，无缩短token上限。

每条用已有FunASR转写后，独立解析编号、日期、时间：编号只接受逐位汉字/阿拉伯数字并保留零；出现十百千万的数量式编号不猜，列无法解析。日期时间解析为数值再比较；多处标签、缺字段、未知读法列无法解析。结果逐字段标记match/mismatch/unparsed，保留转写原文。不用整体字符距离判数字正确，也不把自动匹配当成听感保证。

自动核对完全匹配的样本不要求用户回听。非匹配、解析失败或生成异常列候选问题，并按同一句的多seed/多条件汇总；仅对明确数字缺失/变化/读法疑点提供针对性回听。单ASR无法确定是TTS还是识别错误，不能写成已确认发音错误。本轮不增加识别器或下载模型，不以独立ASR共识冒充人工结论。

资源门槛空闲≥9000MiB、GPU≤20%、Ollama为空；不卸载他人模型。结束释放自有模型，核验生产哈希/原进程/健康。生产不改，1.15不采用，未授权提交推送。音频及转写仅根目录samples本地保存，仓库留匿名数值与字段核对。

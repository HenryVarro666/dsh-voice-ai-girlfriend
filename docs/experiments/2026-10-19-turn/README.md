# 中文断轮数值归档

来源为 2026-10-19 的 apex 实验，2026-10-20 从既有文件导出。这里保留标签、模型数值分数、样本 ID，以及 FLEURS 内部停顿的来源 utterance ID 和长度。没有转写文本、录音、参考音色或模型权重。

- `zho`：Smart Turn v3.2 测试集的 929 条中文合成音，473 条完整、456 条未完。
- `fleurs`：409 条完整中文真人朗读及 224 个内部停顿切点；完整与切点不是独立采样的两组说话者。
- `td3k`：2544 条合成口语文本，1133 条完整、1411 条未完。

数据集来源和裁剪说明见 [实验正文](../../EXPERIMENTS.md)。`scores.json` 的 `rows` 为每条记录，`scores` 内的键沿用原实验别名：`Qwen3-0.6B-end` 是开放 user turn 的结束符与句末标点分数；`large`、`rt`、`zh` 是原实验的三个 FunASR ct-punc 候选；`smart-turn-fp32` 是音频模型分数，仅存在于两套音频数据中。各模型分数并未共同校准，不应直接横向当成置信度比较。

在主仓库根目录运行：

```bash
python scripts/summarize_turn_eval.py
```

输出应与 [RESULTS.md](RESULTS.md) 一致。脚本重新计算 AUC、完整放行率、未完误放率，以及静音兜底策略模拟；不重新运行 ASR 或模型。AUC 对并列分数使用平均排名，判完条件统一为严格大于阈值。

分类表的 FPR 分母是未完样本数；策略表的“被截断句子”分母是全部 409 条完整 FLEURS 源音频，同一句内多个错误只计一次。因此 13.4% 的停顿切点误放与 9.5% 的源句子截断率不是同一个指标。策略平均等待只计算断轮等待，不含 STT、模型评分、网络或回复生成。

归档只包含选定模型的分数，不能用来重算早期 Smart Turn int8、其他 LLM 候选或真实麦克风性能。重新跑推理仍需恢复相同语料、裁剪、ASR 结果和权重。端到端四轮测量位于相邻的独立目录，不与这些分类数据混合统计。

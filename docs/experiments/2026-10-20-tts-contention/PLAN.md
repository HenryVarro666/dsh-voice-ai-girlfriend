# 使用价值判断与 TTS 争用实验

日期：2026-10-20。状态：正式 60 次已完成，结果见 [RESULTS.md](RESULTS.md)。以下协议在正式测量前写定，验收阈值未按结果调整。

## 值不值得继续

结论：值得做一轮可停止、可复算的小实验，暂不支持大规模换模型或训练。项目已有本地中文输入、DSH 工具能力和可打断朗读，具备个人语音助手的使用基础。当前证据仍主要来自合成输入，没有证明真人日常使用稳定。

下一笔投入应回答会改变实现决策的问题。旧记录里首轮约 2.79s，后续三轮约 1.06–1.85s；另有 TTS 首块接近 1.9s 的长尾。这些等待直接影响对话。相比继续试模型，先区分同卡竞争与 TTS 自身波动，成本更低，也更容易决定该优化切句、预热、TTS 参数还是资源安排。

| 方向 | 使用收益 | 当前可验证性 | 本轮决定 |
|---|---|---|---|
| TTS 首声与同卡竞争 | 每轮回答都会经过，定位后可指导延迟优化 | 可复用当前服务，自动固定文本比较 | 现在执行 |
| 真人输入与插话 | 决定能否实际日常使用 | 需要真实说话和耳机/外放样本 | 后续优先；本轮不伪造真人验证 |
| 中文语义断轮 | 可能减少等待，也可能抢话 | 现有模拟已暴露误截断，需真人标签 | 等真人失败集再调参 |
| 原生全双工/数字人 | 交互或展示收益尚未量化 | 新资源和集成成本较高 | 本轮不启动 |

这不是已验证的通用产品需求结论。若真实使用者并不需要语音入口，或后续真人任务错误多于节省的操作，停止主链路扩展，保留可复现实验即可。

## 问题与假设

目标是区分三个原因：

1. 如果 LLM 正在生成挤占算力，decode 组应比仅驻留组更慢。
2. 如果仅模型驻留就影响 TTS，resident 组应比 unloaded 组更慢。
3. 如果 TTS 自身随机波动是主要来源，未加载 LLM 时也会出现相似长尾；不能仅凭一条慢样本归因。

实验只调用当前已测 bridge 的流式接口，不部署维护候选、不修改配置。因此它诊断旧部署的性能，不替代路线 M0 的候选兼容与恢复测试。未来采纳的优化仍需当前构建的 DSH 回归。

## 条件和输入

- 同一 bridge、音色、TTS 配置与 16kHz PCM16 little-endian 输出。
- 四条固定中文文本，覆盖短首句、问句与较长解释句；每条件每文本五次，目标每组 20 次。
- unloaded 组分在模型加载前和卸载后，以检查时间/预热漂移。
- resident 与 decode 组在同一已加载模型下交错、固定随机种子排序。
- TTS 是随机生成，服务端没有按请求固定采样种子；因此统计重复分布与按文本差异，不把一次差值当作因果大小。

| 组 | LLM 状态 | 其他条件 |
|---|---|---|
| unloaded | 本项目 9B 不驻留 | 不卸载其他模型或服务；实验开始时确认本模型未加载 |
| resident | 同一 9B 已加载但没有本实验生成请求 | 与 decode 共享加载状态与上下文配置 |
| decode | 收到同一 9B 首个非空输出 token 后发起 TTS | 记录生成开始/结束，验证首个有声音频到达时仍重叠 |

LLM 使用当前本地 qwen3.5-voice，关闭思考、32K 上下文。每次并发生成均为本实验创建；TTS 完成后关闭自己的生成请求，最终恢复本模型的初始未加载状态。生成文本不提交到 DSH 会话。

## 测量

从 HTTP TTS 请求发起，分别记录响应头、首字节、首个含有声音频的网络块和完整响应。记录音频时长、前导静音、峰值幅度与请求耗时。声音阈值为归一化绝对幅度 0.01，与既有实验一致。

首有声网络块可用时间不是浏览器实际播放，也不是“用户说完到听见”的完整延迟。前导静音是已收到 PCM 中的静音，不能据此断言模型内部生成静音的耗时；handler 可能已裁剪。

记录 GPU 显存/利用率和本项目模型状态，异常、无声、未真正重叠都保留。每组 20 次只做初步中位数、最大值及分布，不声称稳定 p95。效果小或组内波动大时，先扩大重复，不立刻改生产。

## 决策规则

- decode 相对 resident 的中位数增加至少 100ms 且多数文本方向一致：优先研究同卡调度/第一句时机；仍需真实 DSH 验证。
- resident 相对 unloaded 明显变慢：进一步检查显存、资源状态，不直接把原因定为算力竞争。
- unloaded 也有显著长尾：优先 TTS 自身参数、分句、静音生成和预热；不承诺换 GPU 调度就能解决。
- 混合或重复不足：输出未定结论，保留数值，不选择性删除异常。
- 没有实用量级收益：结束此方向，不因已经投入时间而增加系统复杂度。

100ms 是本轮预先选择的工程筛选阈值，不是已验证的人体感知阈值。报告效果大小和样本数。
